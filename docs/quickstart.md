# Quickstart

Need beginner install steps first?
- `docs/install_for_everyone.md`

1. Build (`cmake --preset linux-debug && cmake --build --preset linux-debug`).
2. Launch `dawai`.
3. Load audio to Track 1.
4. Press Play.
5. Open AIFR3D panel and switch mode:
   - TRUE: current mix analysis
   - COMPARE: mix vs reference deltas
   - REFERENCE: pool and benchmark management
