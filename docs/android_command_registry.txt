HOW TO CHANGE A COMMAND

To change the label/description shown in the app:
1. Open:
/home/north3rnlight3r/Projects/AifredVst-2.2.4-beta/server/src/index.js
2. Find ACTION_REGISTRY.
3. Change the description text for that command ID.
4. Restart the Node backend or redeploy the website worker/server path you are using.

Example:

To:
"analysis.run": { id: "analysis.run", description: "Run full analyzer pipeline" }

HOW TO CHANGE WHAT A COMMAND ACTUALLY RUNS

If the command should execute a real shell command:

3. Change the mapped shell command string for that action ID.

HOW TO ADD A NEW COMMAND

1. Add a new entry to ACTION_REGISTRY in:
/home/north3rnlight3r/Projects/AifredVst-2.2.4-beta/server/src/index.js

Example:
"deploy.website": { id: "deploy.website", description: "Deploy the website with Wrangler" }

2. If the command should execute real backend work, add a matching ACTION_COMMANDS entry.

Example:
"deploy.website": "wrangler deploy"

3. Restart the backend.

4. Refresh the Android app Commands tab.

5. Run it from the app as:
action:deploy.website

HOW TO REMOVE A COMMAND

1. Delete the command entry from ACTION_REGISTRY.
2. Delete the matching entry from ACTION_COMMANDS if one exists.
3. Restart the backend.
4. Refresh the Android app.

If you remove it only from ACTION_COMMANDS but leave it in ACTION_REGISTRY:
- the app will still show the command
- the backend will still accept it
- but it will become accept-only and stop executing real backend work
