# DSP Metric Registry (v2.2.4 Beta)

## Comparison Contract

- Live mix comparison uses the nearest detected reference track.
- Target qualification uses the detected genre mean with a strict `±3` window.
- Scoring remains sensitive inside that window by also measuring nearest-reference deviation.

## Spectrum Metrics

- `subBandDb` — `20-60 Hz` sub energy
- `lowBandDb` — `60-200 Hz` bass energy
- `lowMidBandDb` — `200-800 Hz` buildup / body
- `midBandDb` — `800 Hz-2 kHz` core mid balance
- `highMidBandDb` — `2-6 kHz` presence / harshness pressure
- `highBandDb` — `6-16 kHz` brightness / air
- `spectralTiltDb` — overall dark/bright slope
- `averagedBinsDb` — full FFT-derived band array used by the spectrum graph
- `subBandDeltaDb` / `lowBandDeltaDb` / `lowMidBandDeltaDb` / `midBandDeltaDb` / `highMidBandDeltaDb` / `highBandDeltaDb`
  - live minus nearest-reference band deltas carried into scoring and advisory evidence

## UI Usage

- `Mix Signature` summarizes long-horizon behavior across loudness, dynamics, stereo, and tone.
- `Halo` shows the top-level translation result and plain-English state.
- `Candlesticks` show session-to-session movement, not random finance-style noise.
- Supporting meters expose the raw measurements with explicit legends and scales.
- Plugin chat and standalone insight both preserve the last 7 advisory outputs for the current session.
- Advisory text is generated by OpenAI `gpt-5.2` using the live metric payload and deterministic fix evidence.

## Persistence

- Live advisory uses in-memory JSON payloads by default.
- Set `DAWAI_WRITE_ANALYSIS_JSON=1` only when you explicitly want on-disk `analysis/result.json` and `analysis/fix_list.json`.
