# AIFR3D 2.2.4 Beta Minimum PC Requirements

## Windows

- Windows 10 or Windows 11, 64-bit
- 4-core CPU minimum
- 8 GB RAM minimum
- 4 GB free disk space
- 1366x768 display minimum
- Visual Studio 2022 Desktop C++ workload for local source build

## Linux

- 64-bit Ubuntu, Debian, or Arch-based distribution
- 4-core CPU minimum
- 8 GB RAM minimum
- 4 GB free disk space
- `cmake`, a C++17 toolchain, and required audio dependencies

## Recommended

- 6-core or better CPU
- 16 GB RAM
- SSD storage
- dedicated audio interface
- 1920x1080 display

## Online Requirements

- internet access for OpenAI chat
- valid OpenAI API key at `/home/north3rnlight3r/Documents/API_KEY_INDEX/OpenAI API Key.txt`

## Android Admin

- Android 11+
- 4 GB RAM minimum
- internet access
- storage permission for upload workflow
